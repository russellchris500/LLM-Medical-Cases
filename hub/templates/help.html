How the study works

Each case travels one road: write the case → ask the AIs → grade the answers → results. The Home page always shows the step waiting on you.

1. I write cases

On My cases, click New case. A case is a clinical vignette (the question every AI is asked) plus a rubric: one line per thing a good answer must cover. At grading time each answer gets 0, 1, or 2 - 0 if any rubric item is missed or the answer takes an unnecessary risk, 1 if everything is covered but the approach is poor, 2 if it is covered and sound.

You can edit a case later. The site protects earlier work: deleting a rubric item keeps everyone's other judgments, adding one only asks graders about the new line, and changing the question text asks you what to do with answers that already exist.

2. I ask the AIs

On Ask the AIs, tick the models you want and click Run all unanswered cases (or pick specific cases). If you do not have access to some AIs, choose Send it to the PI and their computer runs it instead.

The AIs are run by the Run AI Answers program on your own computer, because chat sites need a real browser and your own logins. One-time setup: create a token on the Connect my computer page, open Run AI Answers, and paste the site address and token. After that: open the program, click the run, click Start. Answers upload to the site by themselves as they are captured, and an interrupted run resumes where it stopped.

3. I grade

Click Grade in the top bar (the number is how many answers are waiting). Answers are shown as A, B, C... - you never see which AI wrote what, and the letters are shuffled differently on every case. For each rubric item mark Covered or Missed; the final two questions appear when everything is covered. Saving moves you straight to the next answer.

If an answer is cut off or garbled, use the Discard button under it - it goes back for a re-run and returns under the same letter. If a rubric item feels wrong, flag it and keep grading; fixing the rubric later only re-asks exactly what the change affects.

The AI judge (PI)

AI judge lets an LLM grade answers the way you do - Covered / Missed per rubric item, then the risk and approach questions - but it is trusted only where it has been checked against real physician grades. A verdict is accepted only if every rubric item matches every physician's judgment on that answer; agreeing on the 0/1/2 score by accident does not count. The judge page shows the acceptance rate, which rubric items the judge reads differently from you (and whether it is too lenient or too strict on each), and its written reason for every mismatch.

Fix a rubric item's wording on the case's edit page and click Test again: your grades carry over as usual, and only the judge is re-run on what changed. The same happens when you change the judge's model or instructions. Each judge records which model it is; by default it skips answers from its own vendor (a model favouring its own family is a known bias) - or let it judge them and the report shows the acceptance rate for self-judged answers separately.

4. The PI's corner

Rankings is the live leaderboard: every grade counts as a match between an AI and a case, fitted into Elo ratings, with inter-rater agreement when several graders scored the same answer. Cross-grading assigns one grader's cases to another for fully blinded second opinions. People invites graders (you email the invitation link yourself). The PI can also write, run, and grade cases like any grader.
